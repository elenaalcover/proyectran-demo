# Reglas de estilo para JavaScript

Esta regla solo se aplica cuando Claude trabaja con ficheros que encajan en `paths`.

- Usa `const` por defecto y `let` solo si la variable cambia.
- Nombres de variables y funciones en español y en camelCase.
- Plantillas de texto (`` `Hola ${nombre}` ``) en lugar de concatenar con `+`.
