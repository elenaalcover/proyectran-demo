# Proyectran demo

Memoria del proyecto: Claude lee este fichero al empezar cada sesión.
Se versiona en git, así que lo comparte todo el equipo.

## Qué es
Repo de formación para aprender a usar Claude Code. El código es mínimo a propósito.

## Comandos
- Ejecutar: `node src/saludo.js Ana`
- Tests: `node --test`
- Subir cambios: se trabaja en `main`; commit y push siempre a través del subagente
  `integrador`, que revisa como una pull request antes de hacerlos.

## Convenciones
- Todo (código, comentarios y commits) en español.
- Cambios pequeños y explicados.
- Ver también las reglas de [.claude/rules/](.claude/rules/).
